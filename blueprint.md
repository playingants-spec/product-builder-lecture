
# Lotto Number Generator

## Overview

This application generates a random set of 6 lottery numbers between 1 and 45. It provides a simple and engaging user interface for users to get their lucky numbers.

## Features

*   **Number Generation:** Generates 6 unique random numbers.
*   **Display:** Shows the generated numbers in a visually appealing way.
*   **User Interaction:** A button to trigger the number generation.
*   **Theme Switching:** Support for Dark and Light modes with persistent preference.
*   **Responsive Design:** Adapts to different screen sizes.
